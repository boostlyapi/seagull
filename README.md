# seagull

Просматривайте контейнеры и образы Docker в браузере, находите нужные записи и управляйте контейнерами без команд в терминале. Можно подключить несколько узлов Docker и следить за ними из одного интерфейса.

## Возможности

- Запускайте, останавливайте и удаляйте контейнеры через веб-интерфейс.
- Просматривайте и удаляйте образы Docker.
- Ищите и фильтруйте записи в интерфейсе.
- Управляйте контейнерами на нескольких узлах Docker и отслеживайте их состояние.
- Выбирайте язык интерфейса: английский, китайский, немецкий или французский.

## Установка

Для сборки нужны Node.js с npm и Docker. Выполняйте команды из каталога исходников, содержащего `package.json` и `Dockerfile`:

```sh
npm install
docker build -t seagull:local .
```

Образ собирается локально: команда запуска ниже не использует образ проекта-донора.

## Использование

Запустите seagull на машине с Docker. Этот пример рассчитан на Linux и стандартный путь к сокету Docker:

```sh
docker run -d \
  --name seagull \
  -p 127.0.0.1:10086:10086 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  seagull:local
```

Откройте http://127.0.0.1:10086. Найдите контейнер в списке и выберите действие: запуск, остановку или удаление. Образы доступны в отдельном разделе интерфейса.

**Доступ к сокету Docker позволяет управлять контейнерами на хосте.** Не публикуйте интерфейс в интернете без ограничения доступа. В примере порт привязан к локальному адресу, поэтому подключиться к нему напрямую с другой машины нельзя.

Чтобы остановить и удалить контейнер seagull:

```sh
docker stop seagull
docker rm seagull
```
